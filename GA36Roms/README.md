# GA36Roms

The current clean-image candidate is [GA7 + GA11 DualBoot](DualBoot/README.md)
for 64-GB+ cards. The earlier separate [GA7](GA7/README.md) and [GA11](GA11/README.md)
images failed the owner's boot test and are retained as historical metadata.

The first intended public binary is the Linux flasher only. No ROM, games,
accounts or private signing keys are included in this local source selection.
The new repository has not been published; owner approval remains required.
