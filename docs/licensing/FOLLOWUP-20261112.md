# License/source search follow-up — 12 November2026

The earlier review omitted evidence present in a separate old working archive.
Those findings have now been checked against the actual P39 components and
primary-source downloads. No ROM, card, public repository or release changed.

## Confirmed and collected

**Amaze:** GA7 contains Amaze3.10/versionCode121. Its full APK SHA256 matches
the developer's original fdroid-flavor release. The exact source commit,
application build scripts, GPL text and README are collected. Upstream
expressly permits ROM preinstallation under GPLv3-or-later conditions. Preserve
its signature/notices and satisfy source and dependency obligations. No new
permission from a seller is needed for this documented GPL inclusion.

**BusyBox:** both the current bootstrap and GA7 copies match the official
ARMv6 1.20.0 download exactly. The official MANIFEST, full BusyBox and uClibc
sources, original Aboriginal1.2.0 build/config/patch source are collected.
Upstream's release announcement identifies hg1535. The upstream source SHA1
values match the historical build script. The original expanded standalone
configuration was not recovered and no bit-identical old rebuild was achieved;
do not describe those last details as proven. The previously source-built
1.36.1 replacement sources/config/patches are also collected, with17 passed
ARM-emulation checks. It is not installed or board-tested and lacks3 old
system applets, so it is not a drop-in release fix yet.

**Current K11:** all42,850 archived source files match the actual K11 tree.
This earlier verified fact does not supply exact sources for inherited modules.

## What the newly found Mali licenses do and do not establish

- CHIP userspace has a redistribution EULA for its own r6p0 GNU/Linux package.
- Bootlin has a documented Allwinner permission statement and package EULA
  for its r6p2/r8p1 Linux blobs, with A33 use mentioned.
- The Allwinner EULA defines permissions for accompanying files and separates
  GitHub users from customers. It also has alteration/transfer restrictions.
- None of those packages contains our identified Android-r4p0 binaries.
  Neither an exact-file match nor permission for the GA11 modified derivatives
  was established. The full candidate EULAs remain private research evidence;
  they are not mislabelled as the license of our ROM's Mali files.

## Still unresolved for the complete ROM

1. Exact Mali400 Android-r4p0 binary redistribution/derivative terms and
   gralloc/license correspondence.
2. Inherited GA7 audio chain: related audio_hw.c has Apache2, but its
   audio_iface/codec/RIL sources and linked liblowpass.a are not covered merely
   by that one header. Earlier BPI manufacturer source comparisons remain open.
3. Vendor display/LCD/GPIO/joystick module corresponding sources/configuration.
   A GPL2 newer serdev joystick driver was located in CodeZombie/GA36-MB-Linux;
   it is a port candidate, not source of our old 3.4 udt_joystick.ko. Source-built
   Mali's r4p0 source lineage is preserved separately in K11.
4. Retained boot0/U-Boot dirty changes and older bytes in the boot prefix.
   Global public commit search returned42 abbreviated-SHA hits, none relevant
   to the bootloader. Newer GA36 projects retain/extract stock boot-chain data
   rather than supply our exact vendor dirty tree.
5. GA7 bulk SDK origin is now explicitly recorded: API24 ARMv7 revision7.
   The original SDK terms distinguish restricted bulk SDK redistribution from
   components covered by their own open-source terms (3.5). Do not call all of
   Android prohibited, and do not assume the whole donor package is cleared.
   Required per-component notices/sources still have to be mapped.

Permissively licensed binaries do not generally require a bit-identical rebuild
or source delivery just because they are binaries. Copyleft source duties and
proprietary permission questions are separate. The inventory deliberately
records uncertainty rather than declaring every unknown file unlawful.

## Practical route

Keep the known working P39 unchanged. A full redistributed image needs the
specific applicable evidence above, or source-built replacements followed by
hardware tests. A local builder that takes stock boot/GPU/vendor files from
the owner's own firmware is another possible distribution format; it is not
implemented or validated for our dual ROM. It avoids shipping those files,
but does not grant new rights over the original firmware. No request has been
sent to any third party. The seller is unknown, so that source channel is not
available from current user information.
