# Source and redistribution scope

MIT applies only to original project-owned code, not blanket licensing of an
Android image, Linux kernel, vendor firmware, dependency or third-party artwork.
Imported files retain their notices/terms. Kernel sources keep Linux GPL terms;
AOSP/Lineage integration files retain their upstream licenses and notices.
Go/Nucular/Shiny/zenity dependencies and fonts have separate notices in the
complete offline flasher source/package. Signing private keys are not included.

The public launcher resources deliberately exclude bundled game logos/covers.
GameLogos and DashboardArt resource lookups can fall back when those optional
resources are absent. Names/hashes in ARTWORK-OMITTED.json identify exclusions;
they do not distribute the artwork. The private image/launcher remains unchanged.

This source tree includes board-specific source/configuration, not donor ROM
binaries, stock firmware, game APK/OBB data, user data or raw device logs.
Local image candidates and matching source archives are separately staged.
Retained binary-input provenance is not resolved merely by collecting source.
No repository/release publication is claimed by this local preparation.
